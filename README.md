# Kam-s-Kandles
This repository is a warm, minimal, luxury e-commerce web experience for selling handcrafted candles made with essential oils, wood wicks, and plant-friendly ingredients — combined with brand storytelling and a portfolio-style showcase. This is a web application (for now) for desktop + mobile responsive. 

Target Users:
- Conscious consumers seeking vegan, plant-friendly home goods
- Gift buyers seeking homemade, artisanal candles
- Interior/lifestyle enthusiasts seeking or drawn to luxury/minimal aesthetics

E-Commerce
- Cart and checkout flow
- Order confirmation email (Resend)
- Order history for logged-in users
- Inventory tracking for administrators
- Invoices
- Stripe payment integration

Contact & Support
- Contact form (name, email, message) --> email via Resend
- FAQ section

Admin Section
- View orders (generate order numbers)
- Manage inventory
- Invoice

Tech Stack
- Frontend: React, HTML, Typescript, Tailwind CSS
- Backend: PHP, FastAPI (Python)
- Database: MS Access, MongoDB
- Payments: Stripe
- Image Storage: Object Storage
